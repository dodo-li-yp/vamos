# Vamos UI 设计规范 v0.1

> 依据：《Vamos PRD v1.0》第 8 节（UI 规范）与第 11 节（给 UI 设计师）。画板尺寸 412×915 dp（安卓逻辑像素），日间、夜间各一套。
> 文件：`vamos-ui-v0.1-day.png` / `vamos-ui-v0.1-night.png`（全部 57 屏总览），`vamos-ui-v0.1-0X-*-day|night.png`（按组），`html/`（可在浏览器打开的源稿），`src/`（生成脚本）。

## 1. 设计系统

### 1.1 颜色（严格沿用 PRD §8，不新增色相）
| Token（Compose） | 名称 | 日间 | 夜间 | 用途 |
|---|---|---|---|---|
| `VmColors.bgPaper` | 宣纸白 | #F4F1E8 | #1A1C1B | 页面背景 |
| `VmColors.textInk` | 淡墨 | #3A3A36 | #E6E2D6 | 主文字 |
| `VmColors.textInk2` | 次文字 | #6E6C64 | #A3A096 | 说明、时间、占位 |
| `VmColors.brandDai` | 黛青 | #5B7A72 | #7FA097 | 主按钮、选中、完成勾、开关 |
| `VmColors.agentQingbi` | 青碧 | #3F8F86 | #5FB3A8 | **只用于 AI 正在执行**：进度条、执行中圆点、后台屏描边、连接中 |
| `VmColors.accentCinnabar` | 朱砂 | #B5473A | #D0645A | **只用于确认、停止、错误** |
| `VmColors.stateAmber` | 琥珀 | #C48A3A | #D9A55A | 警告、等待用户接管 |
| `VmColors.glassFill` | 玻璃 | 白 28%（常态）/ 42%（浮层） | 白 8% / 14% | 玻璃卡片、浮层 |
| `VmColors.glassStroke` | 玻璃描边 | 白 50%，0.5dp | 白 12%，0.5dp | 玻璃描边 |

派生用法（不算新颜色，均由上表 token 叠透明度得到，开发可直接按公式实现）：
- `onAccent`（按钮上的文字）：日间 #FFFFFF；夜间用 `bgPaper` #1A1C1B（夜间黛青/朱砂较亮，白字对比度不够）。**需产品确认，见第 7 节。**
- 色调层 `tone` = `textInk` 6%，`tone2` = `textInk` 10%：次按钮、输入框底、分隔、骨架屏。
- 状态提示条 = 对应语义色 12–18% 透明度 + 主文字色。
- 遮罩：日间 #1A1C1B 32%，夜间黑 50%。
- 夜间浮层（底部面板/对话框/抽屉）= `bgPaper` 上叠 `glassFill` 14%。
- 日间玻璃在宣纸白上几乎不可见，因此日间玻璃卡额外叠 `textInk` 3.5% 打底；背景顶部有黛青 6–10% 的远山水墨剪影，让玻璃有可模糊的内容。
- 模糊：blur 24dp（Android 12+ `RenderEffect`）；Android 11 退化为不透明 92% 面板。

对比度自检（WCAG AA ≥ 4.5:1）：日间 主文字/宣纸 10.1，次文字/宣纸 4.66，白字/黛青 4.70，白字/朱砂 5.35；夜间 主文字/背景 13.2，次文字/背景 6.55，深字/黛青 6.02，深字/朱砂 4.61（夜间白字/黛青仅 2.85、白字/朱砂 3.72，不达标）。
注意：**青碧不做正文文字色**（日间青碧/宣纸 3.39，不达标），只用于图形、描边、圆点、进度条。夜间朱砂作文字时 4.61，仅限 15sp 以上。

### 1.2 字号（sp，PRD §8）
| 角色 | 规格 | 字体 | 用于 |
|---|---|---|---|
| Display | 28/36 SemiBold | 思源宋体（Noto Serif CJK） | 引导标题、首页问候、大数字（10/12、62%） |
| Title | 20/28 Medium | 思源宋体 | 顶栏标题、弹层标题 |
| Subtitle | 16/24 Medium | 系统字体 | 列表主文案、卡片标题、按钮 |
| Body | 15/22 Regular | 系统字体 | 正文、消息气泡 |
| Caption | 12/16 Regular | 系统字体 | 辅助说明、时间、状态 |
| Mono | 13/18 | 等宽 | 仅日志、NOTICE 原文 |

### 1.3 圆角 / 间距
- 圆角：卡片 20dp；弹层、底部面板 28dp；按钮 14dp（胶囊按钮全圆角 24dp）；输入框 16dp；悬浮胶囊全圆角；芯片 16dp；步骤行 16dp；图标底座 12dp。
- 间距：8dp 网格（4dp 只做微调）；页边距 16dp；卡片内边距 16dp；模块间距 24dp（同一模块内元素 12–16dp）；触控热区 ≥ 48dp（所有按钮高 48dp，图标按钮 48×48）。
- 顶栏 56dp；状态栏 32dp（画板示意）；手势条 24dp；底部输入栏 64dp。

## 3. 给开发的标注

- **页面骨架**：`Scaffold` 边到边，`WindowInsets.safeDrawing`；内容区左右 16dp，模块间 16–24dp。
- **顶栏**：高 56dp，返回/菜单图标按钮 48×48，标题宋体 20sp 单行省略。
- **输入栏 `VmInputBar`**：左附件 48dp；中间玻璃输入框最小高 48dp，圆角 24dp，内含 40dp 麦克风（按住说话）；右侧 48dp 发送（黛青）或 `VmStopButton`（朱砂，宽 ≥ 48dp，带文字「停止」）。
- **任务执行卡**：`VmGlassCard` 内边距 16；标题 Subtitle + 右侧 `VmStatusChip`；后台屏小窗 132×240dp，圆角 16，执行中描边 2dp 青碧 + 外圈 4dp 青碧 22%；时间线圆点 12dp，连线 2dp `tone2`。
- **确认面板 `VmConfirmSheet`**：顶部圆角 28dp，内边距 16/12/40；截图 104×180dp 圆角 16；倒计时环 44dp，环宽 4dp；按钮两等分，间距 12。60 秒到时切换为超时态（无倒计时，提示「已视为拒绝，任务已暂停」，按钮「结束任务 / 重新确认」）。
- **支付确认**：无拖拽把手、禁用返回键和下滑关闭；额外一行「支付密码需要你本人在目标 App 内输入」。
- **配对清单**：步骤行 padding 12，圆角 16；序号圆 28dp；当前步骤行底 `tone2`，序号黛青；完成黛青打勾；连接中青碧；失败朱砂叉。
- **更新对话框**：左右边距 24dp，内边距 24，圆角 28；进度条高 8dp；下载中显示 `62%`（Display）+ 速度 + 已下载/总大小；暂停时进度条转次文字色。
- **通知栏**：前台服务通知含进度条与「停止」action（朱砂底仅为示意，系统通知样式以系统为准，action 文案固定「停止」）。
- **悬浮胶囊 `VmCapsule`**：收起时贴屏幕边 48dp 高半胶囊；展开时 56dp 全圆角，左标志、中间当前步骤 + 进度、语音、48dp 朱砂停止；执行中外描边青碧 2dp。
- **Key 显示**：只显示后 4 位（`sk-••••a3f9`），点眼睛图标可临时显示。
- **文案**：全中文，按钮用动词说明动作（「允许并支付」「重新下载」），不使用「了解更多」类空话。

## 4. 关键交互与动效

| 场景 | 说明 |
|---|---|
| 后台屏呼吸描边 | 任务操作中，小窗外圈青碧光晕透明度 22% ↔ 55%，周期 1.6s，ease-in-out 往复；思考中不呼吸 |
| 时间线推进 | 新步骤从下方 8dp 淡入，200ms；完成时圆点由青碧过渡为黛青 |
| 停止 | 点击后按钮立即变「停止中…」，1 秒内中断注入并释放虚拟屏，卡片切换为已停止态并汇报进度；三个入口（App 内、通知栏、胶囊长按）行为一致；音量键组合紧急停止 |
| 确认倒计时 | 环形每秒递减；剩余 10 秒时数字加粗；到 0 切换超时态，任务暂停 |
| 配对自动打勾 | 检测到系统状态变化后序号 → 对勾，缩放 0.8→1，弹簧动画；当前步骤高亮下移；10 秒检测不到出现「我已开启」 |
| 底部面板 / 对话框 | 面板自下滑入 250ms；对话框淡入 + 0.96→1 缩放 200ms；强制更新、支付确认不可通过遮罩/返回关闭 |
| 会话抽屉 | 左滑入 280ms，遮罩淡入 |
| 悬浮胶囊 | 单击展开/收起（宽度弹簧动画）；双击把当前屏幕交给 Vamos；长按说话，执行中长按为停止；可拖动吸边 |
| 浏览器 | 用户触碰网页内容即停止 AI 操作，顶部提示「你接管了页面」 |
| 减少动画 | 系统「移除动画」开启时：呼吸描边改为常亮描边，其余改为直接切换 |

## 7. 需要产品经理确认的点

1. **按钮文字色（onAccent）**：§8 未定义。夜间黛青 #7FA097、朱砂 #D0645A 上白字对比度不足 4.5:1，本稿夜间改用深色 #1A1C1B 文字；日间用白字。是否认可？
2. **青碧作为文字色不达标**（日间 3.39:1）：本稿只把青碧用于图形/描边，不做文字。需确认。
3. **日间玻璃效果**：白 28% 叠在宣纸白上几乎看不出，本稿加了很淡的远山水墨背景和 3.5% 墨色打底。是否接受这一补充？
4. **开源许可页与「设计稿不出现原作者名」**：PRD §0 要求该页展示 NOTICE 原文（含上游署名）；本稿按本次要求用「[上游项目名] / [上游作者]」占位，正式开发按 NOTICE 原文渲染。
5. **版本范围冲突**：§3.3 / §3.2 把「新手任务卡片」「国内模型默认值」「国产 ROM 配对路径」列在 V1 范围的 P0/P1，而 §9 版本规划把它们放在 V1.1。本稿已画出，请确认是否进 V1.0。
6. **执行记录**：§3.2 为 P2，§9 写 V1.1；完成态里有「查看执行记录」入口，若 V1.0 不做需隐藏。
7. **无障碍服务权限文案**依赖 §10 第 10 项 Spike，本稿为占位文案。
8. **「检测不到」的触发时长**未定义，本稿假设 10 秒；配对 6 步的具体拆分 PRD 未列明，本稿按「开发者选项 → 无线调试 → 获取配对码 → 输入配对 → 启动 helper → 验证后台屏」。
9. **确认弹层超时后的按钮**未定义，本稿给「结束任务 / 重新确认」。
10. **停止后的「继续」**是否要求重新确认已执行到的敏感步骤，未说明。
11. **通知栏停止按钮**的颜色受系统通知样式限制，画板中朱砂只是示意。
12. **悬浮胶囊**单击行为未定义（PRD 只说双击、长按），本稿设为展开/收起；长按同时承担「语音」和「停止」，执行中两者冲突，本稿假设执行中长按为停止，需确认。
13. **ui-taste 规则冲突**：团队审美规范不建议用玻璃拟态和米色背景，但 PRD §8 明确要求新中式 + 液态玻璃 + 宣纸白，本稿以 PRD 为准。
